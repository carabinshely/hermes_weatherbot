# Pre-Issue-25 documentation archive

These files preserve the detailed pre-#25 technical documentation that described the
repository before the non-executing product-boundary convergence.

They are **historical reference only**. Their execution-oriented wording, mutable PAPER
commands, "future live" language, and financial-ledger runtime framing are superseded by
the maintained documentation at the repository root and `docs/` paths.

Do not use this archive as product documentation, an operator runbook, or a roadmap.
Current authority is:

- `README.md` for the public producer / internal PAPER / PIP responsibility split;
- `docs/paper-trading.md` for the supported deterministic PAPER experiment interface;
- `docs/pip-publication.md` for signed one-way PIP publication;
- `SECURITY.md` and `docs/dependency-profiles.md` for credential/dependency boundaries;
- the maintained topic document at the corresponding `docs/<name>.md` path.

The archive exists to retain implementation rationale and old regression-contract detail
without allowing that material to misrepresent the current Hermes product direction.
