# Promoted PAPER evidence

Normal deterministic PAPER experiments are generated below ignored
`state/paper-experiments/` and stay local.

Promote a run here only after reproducibility, checksum, size, and secret review. Each
`evidence/paper/<paper_exp_id>/` bundle must contain `manifest.json`, `provenance.json`,
`summary.json`, and `checksums.json`. `evaluations.jsonl` is optional when compact and useful.

Promoted PAPER results are development evidence only. They are not verified profitability,
do not authorize a model/strategy for public or paid use, and must never contain ledgers,
wallet material, signing keys, logs, archives, caches, or temporary files.
